# Grammar Error Detection System

An NLP-based system for detecting and correcting grammatical errors in English sentences.

## Project Objective

The main objective of this project is to develop an NLP system that can identify common grammatical errors in English sentences and provide suitable corrections.

## Technologies

- Python
- NLTK
- spaCy
- Flask
- Pandas
- Scikit-learn

## Features

- English sentence input
- NLP preprocessing
- Grammar error detection
- Error identification
- Grammar correction
- Web-based interface
